## What the application does

PFL Fitness Directive Builder brings directive preparation and roster administration together in a browser-based workspace. It is intended for practical fitness program coordination, including generation of directives that account for exemptions, status follow-up, and related planning activities.

The application is delivered as a client-side single-page app, allowing it to be opened without a complicated installation process. Its interface combines exercise planning, filtering based on restrictions, and output tools so fitness-related information can be organized and shared more easily.

## Included capabilities

- Create training directives with exemption considerations
- Maintain administrative status information for a roster
- Browse exercises by restriction and available equipment
- Plan HIIT sessions and run progression
- Access tools for HAMR practice guidance
- Record waist-to-height ratio information
- Support pregnancy and postpartum training programs
- Produce print-ready results and PDF exports
